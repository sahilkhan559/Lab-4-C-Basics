# Lab 4: Control Structures in C++

## Overview
This lab focuses on implementing control structures in C++. It covers decision-making statements and loops to control the flow of program execution.

## Objectives
- Understand `if`, `if-else`, and `switch` statements.
- Learn `for` and `while` loops.
- Implement conditional statements in C++.
- Check whether a number is even or odd.
- Find the larger of two numbers.
- Print numbers from 1 to 20.
- Create a star pattern using nested loops.
- Practice testing and debugging C++ programs.

## Tasks Completed
1. Pass or Fail using `if-else`.
2. Even or Odd number checking.
3. Find the larger of two numbers.
4. Print numbers from 1 to 20 using `for` and `while` loops.
5. Print a star pattern using nested loops.

## Technologies Used
- C++
- Visual Studio Code
- GCC Compiler
- Git and GitHub

## How to Run
1. Clone or download this repository.
2. Open the project in Visual Studio Code.
3. Open the terminal.
4. Compile the C++ file:

   ```bash
   g++ lab4-control.cpp -o lab4
   ```

5. Run the program on Windows:

   ```bash
   .\lab4.exe
   ```

## Learning Outcomes
After completing this lab, I learned how to use conditional statements, loops, and nested loops to solve basic programming problems. I also practiced testing, debugging, and uploading code to GitHub.
